About JRawr

JRawr 1.0.0 is a port of Rawr v2.3.23.0, the World of Warcraft (Wrath of the Lich King 3.3.5a) gear theorycrafting and optimization tool. It rewrites the original C# (.NET) code in Java 25 and serves it as a Spring Boot web application.

Original Rawr

Copyright 2008 Chadd Nervig, "HugeHoss", "Toskk", and the Rawr Developers.

WotLK 3.3.5a fork (the port source)

JRawr was ported from the RAWR_WotLK_3.3.5a fork, which updated Rawr to pull item data from a WotLK database rather than the post-Cataclysm Wowhead database. That fork was maintained by Magmonix, with Wine/Mono integration and debugging work by Adriano Botti. The original source is available in the JRawr original Rawr snapshot.

Companion addon

A World of Warcraft 3.3.5 addon, JRawrCharacterExporter, exports the current in-game character as Rawr XML for import.
